대학알리미(고등교육재정 알리미/대학공시) API 데이터를 정제하여 계열별 취업률, 신설·폐지 학과 동향, 지역별 취업 역량을 입체적으로 비교·분석한 진로 리포트입니다.

  • 전국 주요 4년제 계열별(공학·인문·자연 등) 취업 지표 산출
  • 수도권 vs 비수도권 대학 진로 성과 지수 비교
